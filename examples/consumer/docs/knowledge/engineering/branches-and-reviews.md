# Branches and reviews

- Branch from `main` as `<issue-key>-<short-slug>`, for example `notes-42-share-expiry`.
- One worktree per task, under `.aidrian/worktrees/<branch>`.
- Rebase on `main` before review. Never force-push a branch someone else reviews.
- A product-sensitive change needs a review from the product owner before merge.
