# Corner Shop

The order and payment backend of a small online shop. Customers pay by card, by store credit, or by both.

- `src/checkout.js` places orders and takes payment.
- `src/payments.js` talks to the card provider.
- `src/orders.js` keeps the orders.

Product rules live in `docs/knowledge/product/`, indexed in `.aidrian/knowledge/`.
Plans for upcoming work live in `plans/`. Run the tests with `npm test`.
