# aidrian harness

This repository ships the `aidrian` plugin for Claude Code and Codex, and runs that plugin on itself.

Optimise for the people and AI sessions in projects that install aidrian: sessions that finish work correctly
with little babysitting, and rules a project can adopt without friction.

Project rules live in knowledge buckets, indexed in `.aidrian/knowledge/`.
Load them with the `knowledge` skill before you plan, edit, or review.
[docs/working-agreement.md](docs/working-agreement.md) holds the rules every change keeps.
