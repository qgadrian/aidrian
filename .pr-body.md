## Summary

Follow-ups from using 0.15.0 on a large consumer pull request. Four review gaps, fixed in one minor release (0.16.0).

1. **Long cited sections lost their tail.** A source was cut at 4000 characters mid-text, so a rule's exceptions past that point reached the reviewer only through a pointer.
   - New optional invariant key `focus` (a string or a list): only the top-level blocks of the cited section that start with those words. It matches whole words, and case and markup don't matter.
   - Focused sources get up to 8000 characters.
   - A long source is now cut between blocks (list item with its nested lines, paragraph, sub-heading, fence), and a note names every block left out.
   - `aidrian lint review` fails on a `focus` that matches nothing, and warns when a source is still over its limit.
2. **Invariants were judged on the delta.** In a later round, `passInput` set the pass base to the earlier head, so `review-not-weakened` was judged on `<earlier head>..HEAD`. It returned `violated` for narrowings of things the same pull request had added. A new head then moved the delta and could hide the verdict.
   - A delta pass still reviews the delta for bugs, but now carries `flowBase` (the merge base).
   - The exec prompt and the agent brief both tell the reviewer to judge every invariant on `git diff <flowBase> <head>`.
3. **Verdict polarity.** A question phrased so that "yes" is the breach inverts holds and violated.
   - The prompt and brief now say holds means the rule is kept, whatever the question's wording.
   - Lint warns on a question that asks with break, remove, weaken, bypass, violate, leak, regress, lose, or drop (not after without, no, never, not, or nothing).
   - Lint warns on a cited text over 200 characters, which restates its rule.
   - Statements are not checked: they have no yes to invert.
4. **Stale plugin installs.** New config key `requires.aidrian` (x.y.z or null).
   - Below it, `aidrian check` fails, and session start adds a line naming the running version and its folder.
   - A plugin older than 0.16.0 rejects the key as unknown, which also fails loudly.

Not done: a Human override for a disputed `violated` verdict. Judging from the merge base removes the false verdicts that prompted it, and the independent stage still challenges each verdict.
