# Working agreement

Every agent and every session follows these rules.

- Read the code before you change it. Reuse the helpers in `src/` before you add new ones.
- Keep a change small: one behavior per pull request.
- A pull request that changes behavior also changes its tests and the doc that describes it.
- Never commit secrets, real user data, or production URLs.
- Plans go in the `plans/` folder of the folder `aidrian state` prints. Task worktrees go in its `worktrees/`.
